# Telegram-бот для учёта доходов

Telegram-бот для ведения личного учёта доходов. Позволяет добавлять доходы, хранить их в SQLite, смотреть статистику, строить график распределения доходов, удалять записи и экспортировать данные в CSV.

## Возможности

- ➕ Добавление дохода:
  - фиксированная сумма;
  - почасовая оплата с автоматическим расчётом суммы;
  - выбор даты: сегодня, вчера или произвольная дата;
  - указание категории.
- ⚡ Быстрый ввод в формате `5000 Фриланс`.
- 📊 Статистика:
  - за текущий месяц;
  - за всё время;
  - за определённую дату;
  - по категориям с процентным распределением.
- 📈 График распределения доходов по категориям.
- 🗑 Удаление последних записей по ID.
- 📥 Экспорт всех записей пользователя в CSV, совместимый с Excel.
- 🧹 Режим «одного окна»: бот удаляет предыдущее сообщение пользователя и своё предыдущее сообщение, чтобы интерфейс оставался компактным.

## Добавление дохода

### Фиксированная сумма

1. Нажмите `➕ Добавить доход`.
2. Выберите `💰 Фиксированная сумма`.
3. Введите сумму.
4. Выберите дату или введите её в формате `ГГГГ-ММ-ДД`.
5. Укажите категорию.

### Почасовая оплата

1. Нажмите `➕ Добавить доход`.
2. Выберите `⏱ Почасовая оплата`.
3. Введите часовую ставку.
4. Введите количество часов.
5. Бот автоматически рассчитает сумму по формуле:

```text
доход = ставка × количество часов
```

6. Выберите дату и категорию. fileciteturn0file2L187-L263

## Быстрый ввод

Если пользователь не находится в процессе другого действия, можно сразу отправить сообщение вида:

```text
5000 Фриланс
```

Бот сохранит `5000` как сумму, а `Фриланс` — как категорию с текущей датой.

Также поддерживается указание вчерашней даты:

```text
5000 Фриланс вчера
```

В этом случае запись будет сохранена датой предыдущего дня. fileciteturn0file2L338-L365

## Статистика

В разделе `📊 Статистика` доступны:

- `📅 За этот месяц` — сумма доходов за текущий месяц;
- `🌍 За все время` — общая сумма доходов;
- `🔍 На определенную дату` — сумма за указанную дату;
- `📂 По категориям` — сумма и процент каждой категории. fileciteturn0file2L288-L335

## График

Пункт `📈 График доходов` строит круговую диаграмму, показывающую распределение доходов между категориями, и отправляет её пользователю как изображение. fileciteturn0file2L266-L285

## Удаление записей

При выборе `🗑 Удалить запись` бот показывает последние 5 записей пользователя с их ID.

Чтобы удалить запись, отправьте её числовой ID. Перед удалением бот проверяет, что запись принадлежит текущему пользователю. fileciteturn0file2L128-L164

## База данных

Используется SQLite-файл:

```text
income_v4.db
```

Таблица `income` содержит:

| Поле | Назначение |
|---|---|
| `id` | ID записи |
| `user_id` | Telegram ID пользователя |
| `amount` | Сумма дохода |
| `category` | Категория |
| `payment_type` | Тип оплаты |
| `rate` | Часовая ставка |
| `hours` | Количество часов |
| `date` | Дата дохода |

Данные запрашиваются с фильтрацией по `user_id`, поэтому статистика, удаление и экспорт работают отдельно для каждого пользователя. fileciteturn0file2L35-L41 fileciteturn0file2L167-L184

## Webhook

Бот работает через Flask webhook. POST-запрос принимается по пути, заданному переменной `WEBHOOK_SECRET`, после чего Telegram update передаётся в `aiogram Dispatcher`. fileciteturn0file2L367-L378

В текущей реализации HTTP-сессия Telegram API создаётся с прокси:

```text
http://proxy.server:3128
```

Это значение указано непосредственно в `core_bot.py`. fileciteturn0file2L370-L373
